# Booking-value source labels — 2026-10-18

The assistant's write origin is no longer presented as proof that it invented a price or duration. Optional `serviceSources` and `addOnSources` annotations persist per name/price/time alongside the existing authoritative draft. Sources are saved account settings, explicit owner text, upload extraction, AI suggestions, or conservatively “Prepared in chat” when the source cannot be verified. No parallel service catalog or transcript-only state was added.

Owner-text evidence is narrowly matched to the named service/add-on and its explicit monetary/time expression. Multiple appointments, missing durations, compound hour/minute lengths, “extra minutes,” saved short BIAB names and ambiguous ranges are covered. Unrecognized wording stays conservative; it does not require the owner to re-enter their details. Upload values and unchanged saved values retain their source. Missing values filled for a first preview are explicitly labelled as suggestions, without relabelling the upload's supplied prices.

The model and browser cannot submit these internal source maps. Assistant-written amounts remain unconfirmed even when their source is the owner's message. Existing authorization, salon locks, strict operation validation, exact review/approval and publication rules are unchanged. Metadata is excluded from the owner-facing before/after list, but remains part of the exact revision hash. Restoring an older draft remaps source annotations to its canonical service/add-on identities. Older immutable revisions are not rewritten; missing annotations get conservative display labels.

Details now shows “Supplied by you,” “Read from your upload” or explicit mixed price/time sources. AI-suggestion notices appear for the appropriate unverified values. Custom website Details also routes owners back to design/link chat instead of exposing preset buttons that the existing custom-source guard would reject. The handoff preserves unsent text, focuses the composer and submits nothing automatically. Manual full-website/Quick Book presets remain available; preserved Canva artwork is clearly described as editable links or a replacement export.
