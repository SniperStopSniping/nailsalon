# Original Canva PDF: owner-to-booking checkpoint

This extends the existing paid builder; it does not replace the draft, publication or booking systems. No hosted/production deployment, production data change, payment or customer communication occurred.

## Owner capability

**My design or menu → Keep my Canva design** now accepts a PDF up to 20 MB, as well as the existing images. PDF pages become bounded, sharp artwork images in their original order and proportions. Preparation/upload progress is visible. The owner confirms use rights once; all selected pages are attached to the existing conversation and business draft. Manual draft controls and single-page sharper replacements use the same converter. A multi-page PDF cannot replace a single existing page accidentally.

The client checks the six-page limit, each page's dimensions and the whole rendered pixel budget before uploading any page. It frees canvases and a dedicated worker, bounds encoding retries, rejects passwords and stops stalled preparation. The pinned PDF.js 6.4.299 compatibility build is loaded only for PDFs. Worker, fonts, character maps and decoders are packaged locally; no CDN, PDF viewer, document-scripting sandbox or arbitrary URL input is used. Only visible page appearances become pixels. PDF scripts, links and forms do not become privileged UI. Worker CSP restricts scripts/network to the application origin. Existing server upload validation and salon ownership checks still apply to every resulting image.

Both upload controls retain progress across a failed save. Identical intact uploads are reused only within the authorized salon and asset role, under its existing database lock. Damaged historical assets are retained and a new upload can recover them. Byte-level deduplication does not promise that different browser encoders produce identical bytes. Earlier revisions and live websites are untouched.

Wide pages receive a phone-readability warning and a portrait-export/editable-redesign suggestion. Rasterizing vector text can preserve detail; it cannot recover missing detail in a low-resolution photo embedded in a PDF. Exact artwork stays editable in Canva; AI and manual controls edit the interactive areas. An editable AI redesign remains the separate choice for changing layout/text directly.
