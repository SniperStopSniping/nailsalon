## Problems found and application fixes

1. A real intake response supplied null service categories for lashes. The command batch was rejected atomically. The preceding intake repair commit retains the first invalid output, permits one metered schema repair and applies only a fully validated batch. This phase adds an additive canonical `other` classification and public Other services group, usable through the existing owner API/editor and booking engine. Existing nail-only tabs and templates retain their behavior; neutral services have no misleading default nail photograph or forced Luster nail template.

   Migration 0111 adds enum values only. A rollout rollback must keep the compatible Other-category readers/UI and disable the AI entry points; it must not remove enum values or relabel existing services as nail appointments.
2. Adjacent Instagram/email overlays overlapped. Validation now names the exact pair and paths for the single bounded repair. Service actions are constrained to this salon's exact supplied service keys at both schema and application boundaries.
3. A model returned fractions while the old contract accepted percent geometry. This produced subpixel links. The AI wire contract now explicitly uses 0–1 fractions, converts once to the existing saved/manual 0–100 percent format, and converts prior areas back before iterative generation. It never guesses units or rewrites old artifacts. Domain overlap, bounds, URL and tenant rules still apply. Effectively invisible generated targets fail validation; old draft targets receive a publication blocker while their saved source stays available for correction.
4. Luna's technically valid first result placed the email link below its printed text and misread the Instagram handle. The owner-facing correction was: “Check that every clickable area lines up with its text or button in my image. The email link seems too low. Fix the link positions and keep the artwork, services and other details unchanged.” Sol medium produced the saved replacement without source intervention. Canva placement now uses the configured design model, `gpt-6.1-sol`, on its first pass and optional repair. Business intake remains Luna. The misread handle was explicitly corrected using Details before artwork approval; it was not silently presented as successful extraction.
5. Two local observation attempts failed around cold route compilation and a Development-server memory restart. Their manifests are retained. Generation was not resent because of those browser failures. A later preview recovered the already saved artifact without another model call. A new geometric landmark test initially observed before CSS smooth scrolling settled; it now explicitly scrolls instantly and waits one animation frame. That test change did not change source or link geometry.
