# Bundled custom-site typography — 2026-10-18

The isolated renderer now embeds versioned, licensed serif, sans and formal script families so new custom websites do not depend on fonts installed on the customer's phone. Cormorant (normal/italic 300–700), DM Sans (normal 100–1000) and Pinyon Script (400) are available to the existing generator as `Luster Serif v1`, `Luster Sans v1` and `Luster Script v1`. They are optional font choices inside arbitrary generated compositions, not new layout presets. Existing system font names are not aliased or changed.

The eight unmodified Latin/Latin-extended WOFF2 assets total 283,444 bytes. Full SIL Open Font License notices, official source URLs, retrieval date, sizes, glyph ranges and SHA-256 checksums ship in `tools/custom-site-renderer/fonts/v1/`. Freeze these aliases/bytes; future replacements need another version. Source: [Cormorant license](https://raw.githubusercontent.com/google/fonts/main/ofl/cormorant/OFL.txt), [DM Sans license](https://raw.githubusercontent.com/google/fonts/main/ofl/dmsans/OFL.txt), [Pinyon Script license](https://raw.githubusercontent.com/google/fonts/main/ofl/pinyonscript/OFL.txt).

`font-pack.mjs` reads and checks only the fixed local pack, without model input or network requests. Data-font CSS is embedded inside the trusted renderer boot and covered by its existing SHA-256 CSP script hash. CSP permits `font-src data:` while retaining opaque-origin sandboxing, no connect/frame/object/form capabilities, worker-only generated interactions and canonical booking bindings. The browser never contacts Google Fonts. New model output cannot define font faces, use font URLs or replace bundled families. Previously permitted immutable local-font definitions remain readable/editable; URL-bearing CSS is rejected for both old and new source. No schema migration or provider/package change is required.
