# Recommended posting order

Start with a small coherent set. The full library is available for review; publishing remains a user decision.

| Order | Tutorial | Salon benefit to lead with |
|---|---|---|
| 1 | Online booking | Let clients choose a treatment and available time. |
| 2 | Booking page style | Make the booking page feel like the salon. |
| 3 | Luster Gel Manicure setup | Keep price and appointment length clear. |
| 4 | French Tips, Chrome and removal extras | Reserve the right time and show extra costs. |
| 5 | Calendar | Find and open a booked visit quickly. |
| 6 | Manual appointment | Keep phone and in-person bookings together. |
| 7 | Appointment reminders (setup guide) | Choose reminder timing and channels. |
| 8 | No-show reporting (Feature Preview) | Record confirmed nonattendance and eligible shared history. |
| 9 | No-show corrections (Feature Preview) | Correct a mistake while retaining its audit trail. |
| 10 | 100 starter SMS credits | Claim the eligible one-time allowance after verification. |
| 11 | Checkout | Finish a visit and keep its payment record together. |
| 12 | Client history | Keep useful visit information close to the next booking. |
| 13 | Smart Fit | Show an actual qualifying discounted time and saved total. |
| 14 | Rebooking reminders (setup guide) | Set the invitation timing and wording for returning clients. |
| 15 | Honest review requests (setup guide) | Save the salon’s Google review link without rewards. |

Use Highlights for **Book**, **Your Page**, **Services**, **Clients**, **No-Shows**, **Messages**, **Team** and **Payments**. Use the matching covers and the full-size MP4 exports, rather than screen-capturing the gallery.

Keep Feature Preview labels until release verification. Describe setup guides as setup; they do not demonstrate delivered texts/emails or connected Stripe/Google outcomes. Do not post archived advanced-catalog footage, blocked provider flows or hidden/retired features as available.

The videos use text and synchronized hand taps. They are silent by design; music or narration can be added in a later approved edit without changing the instructional timing. Check the final file inside Instagram on a physical phone before approving the reusable posting layout.
