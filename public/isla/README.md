# Isla custom booking assets

Source: the user-approved Isla booking concept (6 October 2026), with its approved mobile hero revision.

- `isla-logo-original.jpg`: user-supplied Isla Nail Studio logo, retained unchanged.
- Salon photographs: unchanged copies of Isla's existing public service images, captured for the approved concept. They are editorial studio images, not a live Instagram feed. Service-card images continue to come from the current catalog.
- `isla-paper-palm.png`: generated decorative paper/palm artwork from the approved desktop concept.
- `palm-frond.svg`: decorative illustration from the approved mobile header source.
- Fonts: locally hosted Cormorant Garamond, DM Sans and La Belle Aurore, from the approved concept. CSS uses Isla-specific font aliases to avoid altering other salons.

Only presentation is specialized. Prices, durations, availability, required extras, technician eligibility, request/instant confirmation, payment requirements and appointment management remain governed by the existing booking engine.
