The burgundy result retains white outer space, monogram, deep red information panel, divided columns and separate thank-you block. ## Improvements made from actual use

- Fixed standalone suggestion shortcuts discarding a supplied business name/location. Mixed answers now pass through structured intake.
- Strengthened first-message service capture after a real request omitted Acrylic Nails/Russian Manicure. The final real-provider run captured Gel-X and BIAB immediately, without a follow-up service prompt.
- Added frozen, expiring, owner-revocable view-only preview links. Later reset/edit operations do not replace earlier examples. Tokens have 256 random bits; only hashes are stored. Owner creation checks authorization, exact revision and privacy; public reads expose only the website projection. Full-address drafts cannot be shared.
- Added bounded support for SVG preserveAspectRatio after the burgundy generation paid for an unnecessary automatic repair. Network resources, executable markup and unsupported values remain rejected. Its initial and repaired provider outputs remain retained privately; the saved design was not manually repaired.
- Fixed component-test cleanup ordering so async preview effects are disposed before browser globals are restored.

The initial anonymous capture reached Vercel login, not the website, and therefore showed Vercel's referrer header. Only the isolated test alias received a viewing override; project-wide/production protection was unchanged. Luster's anonymous owner API reads and writes still return 401. Shared pages render anonymously with no-referrer/no-store/noindex and disabled booking. Earlier links remained unchanged after later resets.
