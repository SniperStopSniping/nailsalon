## Limitations and failed attempts

The owned Canva screenshot still has the original low-resolution fine print; preserving it cannot reconstruct missing detail. Original PDFs/sharper exports and editable redesign remain the appropriate alternatives already supported by the application. The generated interpretations also retain the previously documented differences from their references; a render/booking check is not proof of exact visual reproduction or universal professional design quality.

The first image-inspection attempt tried to scroll a deliberately hidden gallery image and stopped. A later screenshot-preparation attempt used an extreme `-100000` wheel delta; it produced a blank first-screen capture and a missed subsequent click, so it was not accepted. Ordinary 650-pixel wheel scrolling followed by the real service click passed. The final runner captures the first screen on arrival, then checks later lazy images and native booking navigation. Failed captures/diagnostics remain private in `/tmp/luster-ai-saved-sites-readonly-hZ3K8Z/` and `/tmp/luster-ai-saved-sites-readonly-mXQ0AD/`; no generated source was changed to obtain the passing result. The extreme gesture is not claimed as verified behavior.

Hosted resource isolation, coordinated Development-key rotation, deferred Stripe sandbox acceptance, combined release CI/review and protected-main publication remain separate gates. No push, hosted deployment, production migration or production-data change occurred.
